# Red Hat Enterprise Linux runner images now generally available

![](https://github.blog/wp-content/themes/github-2021-child/assets/img/featured-v3-improvements.svg)

Red Hat Enterprise Linux (RHEL) 9 and RHEL 10 images for GitHub-hosted larger runners are now generally available. Originally introduced in [public preview](https://github.blog/changelog/2026-06-24-red-hat-enterprise-linux-runner-images-are-now-in-public-preview/) in June 2026 in partnership with Red Hat, these images are now fully supported for production workflows in GitHub Actions.

You can use RHEL images to run your workflows on the same operating system you deploy to, or as the foundation for custom images that include your required tools, dependencies, and configurations.

To get started, create a new Linux x64 larger runner and choose your desired RHEL image under partner images. If you’ve been using RHEL images during the public preview, no action is required. Your existing runners and workflows will continue to work as-is.

RHEL images are available for larger runners on GitHub Team and GitHub Enterprise Cloud plans. To learn more, see [Managing larger runners](https://docs.github.com/actions/how-tos/manage-runners/larger-runners/manage-larger-runners) and [Using custom images](https://docs.github.com/actions/how-tos/manage-runners/larger-runners/use-custom-images).
