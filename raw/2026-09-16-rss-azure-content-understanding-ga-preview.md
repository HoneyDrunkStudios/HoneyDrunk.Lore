# From Sync APIs to support for the GPT-5 model series and agentic workflows: What’s new in Azure Content Understanding – August 2026

Source: [From Sync APIs to support for the GPT-5 model series and agentic workflows: What’s new in Azure Content Understanding – August 2026](https://devblogs.microsoft.com/foundry/azure-content-understanding-updates-august-2026/)

## Attributed content summary

Microsoft distinguishes two Azure Content Understanding tracks: a refreshed generally available CU 1.0 API and a CU 2.0 public preview. The GA update expands model choices and revises grounding efficiency and confidence scoring; reported accuracy and token savings come from internal evaluations.

The preview adds synchronous Read and Layout operations, contextualization from labeled examples, semantic document chunking, finer classification boundaries, and agentic document reasoning. Structure-aware chunks aim to keep related content together for retrieval. Classification confidence provides a signal for routing uncertain results to further checks or human review.

Custom contextualization training inputs remain in customer-controlled Azure Storage according to the announcement. The article separates production API version 2025-11-01 from preview version 2026-06-01-preview.

For Lore-style ingestion, evaluate extraction quality, provenance, cost, and review thresholds on representative documents. Do not conflate preview features with the GA contract or assume vendor aggregate improvements will apply to a particular corpus.
