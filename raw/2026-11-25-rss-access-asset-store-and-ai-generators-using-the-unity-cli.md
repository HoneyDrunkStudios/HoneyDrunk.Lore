# Access Asset Store and AI Generators using the Unity CLI

### Your Coding Agent Can Now Access the Unity Asset Store

Today, we’re excited to announce that we’re making it easy and seamless for the AI tool of your choice to find, select, download, and import assets from the [Unity Asset Store](https://assetstore.unity.com/) directly into your Unity projects. Imagine asking your agent to block out a forest clearing. It needs a pine tree, and your project doesn’t have one. So your agent goes and gets one. It searches the Asset Store, finds a tree in the right style, downloads that single model (not the 2 GB environment pack it came in), and drops it into your scene. You didn’t open a browser, and you didn’t import a thing.

This is possible because now the [Unity CLI](https://unity.com/blog/meet-the-unity-cli) connects coding agents like [Claude Code](https://unity.com/blog/unity-plugin-for-claude-code), [Codex](https://unity.com/blog/unity-plugin-codex), [Grok Build](https://unity.com/blog/unity-plugin-grok), and [Google Antigravity](https://docs.unity.com/en-us/ai/unity-plugin/antigravity) to the Unity Asset Store and 60+ AI asset generators, so an agent can find, download, or generate assets directly into a Unity project.

It’s just one of the updates we’re announcing today, as we continue to deliver tools that help meet you where you work.

### Grab one prefab, not the whole pack

You’ll now also be able to choose individual assets from an asset pack instead of having to download the entire pack for ***free assets or for those you already own***. That’s because today we’re also excited to release the Asset Library plugin which combines with the Unity CLI to break up the old .unitypackage format, so individual prefabs show up when you need them. If all you need is one wooden barrel, you can now get ***just*** ***one*** wooden barrel, not a 650 MB medieval props pack to dig through.

The Asset Library plugin lets you describe what you want in plain language, find it, and drag it into your scene. Only the files that asset needs get downloaded, and import and file management happen automatically.

You also get data the Asset Store never showed before, like triangle count and animation rigging, so you can tell whether an asset is production ready before it touches your project.

### Can’t find it? Your agent can make it

Some assets don’t exist yet. The exact sprite, a 3D model in a style nothing on the store matches, a sound effect too specific to have ever been recorded. And it’s also possible there isn’t an artist on your team. Starting today, your coding agent can use AI generators to create the assets you can’t find or have an artist create. These generators are also available through the Unity CLI, so that you can easily generate artifacts if you need to.

One command gets you sprites, 3D models, sound effects, and more, plus edits like background removal and upscaling. You can pick from 60+ models, and quotes are free, so you see the price before you spend any credits.

Every generated file records its model, its prompt, and its cost. Months later, when someone asks where a file came from, you have the answer.

It also makes a good placeholder. If the forest clearing needs a sound today and your artist is recording the real one next month, your agent fills the gap now. You can even ask your agent to pull up the file’s record so you know what to replace later.

### One Unity login for all of it

Sign in once with the Unity ID you already have. The Asset Store and all 60+ generation models are part of your Unity account and the [plan](https://unity.com/products) you’re associated with which comes with AI credits. When your agent searches the store or asks for a quote, it acts as you, with your entitlements and your spend. There’s no second account to create and nothing extra to set up for each model.

And you keep the agent you like. It reaches the store and the generators through the same Unity CLI it already uses to work with the Editor.

We want to meet you where you already work, and that means giving you more choice in how you build with Unity.

### How can you get started today?

The Asset Store in the CLI and AI Generators in the CLI are both in open beta. The Asset Store CLI access to free assets is available to anyone. The AI Generators with CLI are part of Unity's AI tools and included on all [Unity’s paid plans](https://unity.com/products) and use the credit allocation that comes with your plan.

Documentation for the Asset Store in the CLI is [here](https://docs.unity.com/en-us/asset-store/asset-library/introduction), and documentation for the AI generators is [here](https://docs.unity.com/en-us/ai/generators-cli).
