# Azure Container Apps Express is now Generally Available

Attributed summary of the fetched article.

Microsoft announces general availability of Azure Container Apps Express. Deployment begins with a container image, region, and application configuration; the service provisions the underlying infrastructure without requiring a separately configured environment. The article describes scale-to-zero and startup optimized for sub-second performance.

Express runs on Azure Container Apps Sandboxes and offers a focused subset of Container Apps functionality. Microsoft directs workloads needing greater networking control, GPU compute, advanced configuration, or Dapr toward standard Container Apps environments. The announcement reports availability in more than forty regions and links to the current region list.

HoneyDrunk application: evaluate Express for simple web APIs and agent-created deployments, using required networking and runtime features as selection gates. Startup claims are vendor descriptions, not measurements of HoneyDrunk workloads. Check current regional support before implementation.
