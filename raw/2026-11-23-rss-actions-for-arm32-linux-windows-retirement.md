# Actions for ARM32 Linux & Windows retirement

GitHub Actions hosted runners will be ending support for ARM32 job execution on Windows and Linux by 8th Dec 2026. This follows our [end of support for node20](https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions/)  where Node 24 does not support ARM32.

This includes the removal of support on hosted runners for native AArch32 User-space execution.
