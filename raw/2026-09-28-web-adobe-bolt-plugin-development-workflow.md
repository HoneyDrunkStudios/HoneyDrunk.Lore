# Source capture

Justin Taylor describes updates to the open-source Bolt frameworks for Adobe plugins. Bolt UXP adds asynchronous command execution, source-level debugging, centralized error handling, Premiere helpers, and scripts to test packaged plugin installation. Asynchronous execution supports external tools without blocking the plugin interface.

Bolt Express improves sandbox reloads and adds typed messaging in both directions between its frontend and sandbox. The frameworks retain access to underlying platform APIs and Vite configuration rather than hiding those extension points.

HoneyDrunk application: assess a maintained plugin scaffold for creator-tool automation, focusing on reproducible packaging, debug visibility, and typed boundaries. Test host compatibility and packaged installation as part of delivery.

The author's report is not a compatibility certification. Readiness for additional Adobe hosts is contingent on public APIs; the article includes an unresolved editorial note about that timeline. Treat those future integrations as unconfirmed.
