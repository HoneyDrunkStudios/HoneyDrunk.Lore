# New Copernicus Node For Testing UV Layouts On 3D Models

Source: https://80.lv/articles/new-copernicus-node-for-testing-uv-layouts-on-3d-models/

Amber Rutherford Senior Editor 08 July 2026 New Copernicus Node For Testing UV Layouts On 3D Models # News # Houdini SideFX Labs' UV Grid Texture COP is now available. 
When a model is unwrapped into UV space, it can be difficult to determine if the mapping is accurate. This new Copernicus node creates procedural textures designed to test UV layouts, texture orientation, texel density, and distortion. The generated texture can be customized using tile colors, markers, outlines, and text labels. 
The resulting image can be saved to disk or previewed using UV Visualize SOP, which projects it onto geometry to help analyze UV placement, orientation, distortion, seams, and UV island distribution.
