# What’s new in Microsoft Foundry: July and August 2026

Original source: [What’s new in Microsoft Foundry: July and August 2026](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-july-august-2026)

## Source-content summary

Microsoft's July-August roundup describes general availability of Foundry Hosted Agents, Voice Live integration, and Toolboxes. The worked deployment example scaffolds an agent, tests it locally, invokes it, and deploys it using Azure Developer CLI; it also identifies model and hosting charges and networking dependencies.

Toolboxes move authentication and credentials outside agent code behind an MCP-compatible endpoint. Tool search and agent skills remain preview features in this account. The article also covers Azure-hosted Claude capabilities, model routing, and local inference changes.

At the stated August baseline, Python and JavaScript/TypeScript SDKs are stable at 2.5.0 and Java at 2.4.0, while the .NET 3.0.0 line remains preview. Runtime and management coverage differ by language. HoneyDrunk relevance: check SDK maturity, private networking, credential ownership, and actual runtime support before migrating a .NET agent to a managed hosting path.
